# Lynfort — Phishing Simulation Lab

Laboratório educacional de simulação de phishing e conscientização
em segurança da informação.

## Objetivo

Desenvolver um cenário corporativo fictício, uma página educativa
e, futuramente, indicadores de participação e relatórios.

## Ambiente

- Kali Linux em máquina virtual
- Git
- Python 3
- HTML e CSS

## Escopo

Os exercícios utilizam dados fictícios em ambiente controlado.
O projeto não solicita nem armazena senhas.

## Estado atual

Versão 1 em desenvolvimento: página educativa local.
